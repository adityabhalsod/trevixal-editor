# Using the editor

These pages describe the assembled editor as a person using it sees it: what
each part of the screen does, where the commands live, and what the files it
saves contain. They are written for anyone who has the editor in front of
them, whether that is the [demo](https://github.com/adityabhalsod/trevixal-editor/tree/main/examples/full-editor),
`mountFullEditor` in your own app, or a chrome you assembled yourself from
`@trevixal/ui`, which shares every menu and shortcut described here.

- **[A tour of the editor](./tour)**: the menubar, toolbar, popups, palette, panels, review bar and status bar
- **[Files](./files)**: saving, opening, importing, downloading, printing, and what an export carries
- **[Appearance](./appearance)**: themes, presets, custom CSS, fonts, page view, widths, focus and typewriter modes
- **[Protecting a document](./protection)**: passwords, expiry, restrictions and read-only mode
- **[Reviewing with tracked changes](./review)**: suggesting mode, accept and reject
- **[Writing help](./writing)**: grammar, passive voice, readability, statistics and goals
- **[Several documents](./workspace)**: the workspace panel, tabs, folders and templates
- **[Keyboard and typing shortcuts](./shortcuts)**: every key, input rule, slash command and emoji trigger
- **[Every menu command](./menus)**: the whole menu tree

If you are integrating rather than using, start at [Getting started](../guide/getting-started).
